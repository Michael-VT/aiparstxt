# aiparstxt — Багатомовний санітайзер тексту та аналітик AI-криміналістики

Набір утиліт командного рядка для очищення текстових файлів шляхом заміни неприпустимих символів на '?'. Реалізовано на 6 мовах для порівняння продуктивності. Включає видалення AI-водяних знаків та **статистичний криміналістичний аналіз** для визначення ймовірності генерації тексту ШІ.

**Доступно:** [English](README.md) | [Русский](README.RU.md) | [Українська](README.UA.md) | [Português](README.PT.md) | [Français](README.FR.md) | [Deutsch](README.DE.md)


## Можливості

- **Санітизація тексту** — заміна неприпустимих символів на '?' у 6 мовних реалізаціях
- **Видалення AI-водяних знаків** — видалення невидимих Unicode-символів, що вставляються AI-системами
- **Аналітика AI-криміналістики** — евристичний статистичний аналіз для оцінки ймовірності авторства ШІ (Python)
- **Розширені версії детекції** — покращена форензична аналітика доступна для всіх 6 мов ⭐

## Припустимі символи

- Цифри: 0-9
- Латинські літери: A-Z, a-z
- Російські літери: А-Я, а-я (включаючи Ё/ё)
- Знаки пунктуації та символи: []{}()-=_+!@#$%&*;'/.,<>'"`~
- Пробільні символи: пробіл, табуляція, перенесення рядка

Усі інші символи замінюються на '?'.

## Видалення AI-водяних знаків

Санітайзер підтримує видалення невидимих символів-водяних знаків, що використовуються різними AI-системами для маркування згенерованого тексту:
- Символи нульової ширини (ZWSP, ZWNJ, ZWJ, ZWNBSP)
- Невидимі символи форматування (Word Joiner, Invisible Times тощо)
- Селектори варіацій
- Тегові символи
- Символи двонаправленого перевизначення

Див. `ai-chart.txt` для повного довідника.

## CLI — Санітайзер (усі 6 мов)

```bash
partxt <вхідний_файл> [опції]
```

Опції:
  -o, --output <файл>       Вихідний файл (за замовчуванням: <вхідний>.ed.txt)
  -r, --report <файл>       Файл звіту (за замовчуванням: report_<мова>.txt)
  --no-edit                Не створювати файл .ed.txt
  --no-report              Не створювати файл звіту
  -w, --no-words           Не включати частотний словник у звіт
  --remove-watermark       Видалити AI-водяні знаки (приховані/невидимі символи)
  -h, --help               Показати довідку

### Окремо

```bash
# Стандартні версії
python3 partxtpy/partxt.py testdata/sample.txt
python3 partxtpy/partxt.py testdata/sample.txt --remove-watermark

# Розширені версії з AI-форензичною аналітикою ⭐
python3 partxtpy/partxt-ext.py testdata/sample.txt
python3 partxtpy/partxt-ext.py testdata/sample.txt --remove-watermark

cargo run --release --manifest-path partxtrs/Cargo.toml -- testdata/sample.txt
cargo run --release --manifest-path partxtrs/Cargo.toml --bin partxt-ext -- testdata/sample.txt -- --remove-watermark

cd partxtgo && go run . testdata/sample.txt
cd partxtgo && go run main-ext.go testdata/sample.txt --remove-watermark

cd partxtcpp && make && ./partxt testdata/sample.txt
cd partxtcpp && make && ./partxt-ext testdata/sample.txt --remove-watermark

node partxtnode/partxt.js testdata/sample.txt
node partxtnode/partxt-ext.js testdata/sample.txt --remove-watermark

bun run partxtjs/partxt.js testdata/sample.txt
bun run partxtjs/partxt-ext.js testdata/sample.txt --remove-watermark
```

### Усі разом

```bash
# Тільки стандартні версії
./run_all.sh testdata/sample.txt

# Розширені версії з AI-детекцією
./run_all_extended.sh testdata/sample.txt
```

У корні проєкту доступні чотири варіанти аналітичних скриптів:

| Скрипт | Метрики | AI-фрази | Особливості | Рекомендоване використання |
|--------|----------|----------|-------------|---------------------------|
| `parscgpt.py` | 8 базових | 21 | Тільки базові метрики | Застаріла/тестова |
| `parscgptv1.py` | 8 базових + інтерпретація | 21 | + Стоп-слова, достовірність | Базова детекція |
| `parscgptv2.py` | 8 базових + покращена інтерпретація | 21 | + Чистий вивід | **Стандартна детекція** ✅ |
| `parscgpt-ext.py` | **17 просунутих метрик** | **70+** | + Лінгвістичний аналіз, зважений скоринг | **Розширена детекція** ⭐ |

### Інтегровані розширені аналізатори (Всі 6 мов) ⭐

Розширені версії базових санітайзерів тексту (`partxt-ext`) тепер доступні для **всіх 6 мовних реалізацій** з покращеною AI-форензичною аналітикою:

| Мова | Розширений бінарний | Файл звіту | Особливості |
|----------|----------------|-------------|-----------|
| Python | `partxtpy/partxt-ext.py` | report_py-ext.txt | 11 основних метрик + AI-оцінювання ймовірності |
| Rust | `partxtrs/target/partxt-ext` | report_rs-ext.txt | Ті ж метрики, що й Python, скомпільована продуктивність |
| Go | `partxtgo/main-ext.go` | report_go-ext.txt | Ті ж метрики, скомпільована продуктивність |
| C++ | `partxtcpp/partxt-ext` | report_cpp-ext.txt | Ті ж метрики, скомпільована продуктивність |
| Node.js | `partxtnode/partxt-ext.js` | report_node-ext.txt | Ті ж метрики, JavaScript runtime |
| Bun | `partxtjs/partxt-ext.js` | report_bun-ext.txt | Ті ж метрики, оптимізований JavaScript |

**Покращені можливості в розширених версіях:**
- 11 основних AI-форензичних метрик (лексичне різноманіття, ентропія, вибухоподібність, повторюваність патернів тощо)
- Детекція AI-фраз з 70+ підозрілих фраз
- Детекція підозрілих Unicode-символів
- Статистичне AI-оцінювання ймовірності (0-100%)
- Рівні достовірності (НИЗЬКИЙ/СЕРЕДНІЙ/ВИСОКИЙ) на основі довжини тексту
- Детальний аналіз сигналів з візуальними індикаторами
- Інтерпретація кожної метрики з практичними рекомендаціями

## Стандартні метрики (Всі розширені версії)

| Метрика | Опис | Цінність для детекції AI |
|--------|-------------|---------------------|
| `lexical_diversity` | Унікальні слова / всього слів (після видалення стоп-слів) | AI має нижче різноманіття |
| `repetition_score` | Частка слів, що зустрічаються більше одного разу | AI повторює частіше |
| `entropy` | Ентропія Шеннона розподілу частот слів | AI має ненатуральном рівномірний розподіл |
| `burstiness` | Коефіцієнт варіації довжин речень | AI має надто рівномірну структуру речень |
| `pattern_repetition` | Частка повторюваних патернів довжин речень | AI використовує шаблони |
| `punctuation_density` | Кількість знаків пунктуації / всього символів | AI може перестаратися з пунктуацією |
| `ai_phrase_hits` | Збіги з 70+ куратованими AI-типовими фразами | Прямий AI-підпис |
| `unicode_symbols` | Кількість підозрілих Unicode-символів | Технічні AI-маркери |
| `avg_word_length` | Середня довжина слів | AI використовує простіший словник |
| `word_length_variance` | Варіація довжин слів | AI тексти більш однорідні |
| `confidence` | На основі кількості слів (НИЗЬКИЙ <300, СЕРЕДНІЙ 300-999, ВИСОКИЙ ≥1000) | Індикатор надійності |

| Умова | Бали | Покращення |

| Ентропія < 5.0 | **+25** | ↑ +5 проти стандартної |
| Вибухоподібність < 0.35 | **+20** | ↑ +5 проти стандартної |
| Повторюваність патернів > 0.35 | **+20** | ↑ +5 проти стандартної |
| AI-фрази ≥ 3 | **+20** | ↑ +5 проти стандартної |
| Оцінка повторюваності > 0.5 | +15 | Без змін |
| Щільність пунктуації > 0.04 | +5 | Без змін |

| Варіація довжин слів < 1.5 | **+8** | 🆕 Нова метрика |

**Всього** обмежено 100% з коригуванням фактора достовірності (80%-100% на основі довжини тексту).

## Розширені метрики (тільки parscgpt-ext.py) ⭐

Для найбільш всеосяжного аналізу, автономний `parscgpt-ext.py` надає 17 просунутих метрик:

| Метрика | Опис | Цінність для детекції AI |
|--------|-------------|---------------------|
| `avg_word_length` | Середня довжина слів | AI використовує простіший словник |
| `word_length_variance` | Варіація довжин слів | AI тексти більш однорідні |
| `pronoun_ratio` | Співвідношення займенників до загальної кількості слів | AI надмірно використовує займенники |
| `readability_score` | Індекс читабельності Flesch | AI тексти "занадто читабельні" |
| `passive_voice_density` | Частота пасивних конструкцій | AI надає перевагу пасивному стану |
| `adj_noun_pair_diversity` | Унікальні комбінації прикметник-іменник | AI має обмежені комбінації |
| `structural_uniformity` | Повторюваність патернів початку речень | AI використовує шаблони |
| `quantifier_overuse` | Частота слів-кваліфікаторів | AI надмірно використовує кваліфікатори |

Використовуйте `parscgpt-ext.py`, коли вам потрібен найглибший лінгвістичний аналіз за межами інтегрованих санітайзерів.

**Ключові відмінності: Розширені проти Стандартних версій**
- Надає **9 додаткових метрик** для глибшого аналізу
- Показує **детальний скоринг** замість однієї ймовірності
- Включає **специфічну інтерпретацію** для кожної метрики
- Пропонує **покращену надійність** з адаптацією до довжини тексту
- Детектує **більше AI-патернів** — 70+ фраз проти 21 в стандартній версії

- Формул обчислення метрик
- Ваг та порогових значень моделі скорингу
- Правил інтерпретації
- Специфічних для мови рекомендацій

## Формат звіту (Санітайзер)

Кожен звіт містить:
- Час виконання
- Режим (заміна/видалення + статус видалення водяних знаків)
- Видалені водяні знаки (з кодами Unicode)
- Замінені символи (з кількістю входжень)
- Частотний словник слів (відсортований за зростанням частоти)

**Розширені версії** додатково включають:
- Секцію AI-форензичних метрик
- AI-оцінку ймовірності з рівнем достовірності
- Аналіз сигналів з візуальними індикаторами
- Інтерпретації, специфічні для метрик
