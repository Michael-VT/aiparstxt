# aiparstxt — Мультиязычный санитайзер текста и анализатор AI-текстов

Набор утилит командной строки для очистки текстовых файлов путём замены недопустимых символов на '?'. Реализовано на 6 языках для сравнения производительности. Включает удаление AI-водяных знаков и **статистический криминалистический анализ** для определения вероятности генерации текста ИИ.

**Доступно на:** [English](README.md) | [Русский](README.RU.md) | [Українська](README.UA.md) | [Português](README.PT.md) | [Français](README.FR.md) | [Deutsch](README.DE.md)


## Возможности

- **Санитайзация текста** — замена недопустимых символов на '?' в 6 языковых реализациях
- **Удаление AI-водяных знаков** — удаление невидимых Unicode-символов, вставляемых AI-системами
- **Криминалистическая аналитика AI** — эвристический статистический анализ для оценки вероятности авторства ИИ (Python)

---

## Допустимые символы

- Цифры: 0-9
- Латинские буквы: A-Z, a-z
- Русские буквы: А-Я, а-я (включая Ё/ё)
- Знаки препинания и символы: []{}()-=_+!@#$%&*;'/.,<>'"`~
- Пробельные символы: пробел, табуляция, перевод строки

Все остальные символы заменяются на '?'.

## Удаление AI-водяных знаков

Санитайзер поддерживает удаление невидимых символов-водяных знаков, используемых AI-системами для маркировки сгенерированного текста:
- Символы нулевой ширины (ZWSP, ZWNJ, ZWJ, ZWNBSP)
- Невидимые символы форматирования (Word Joiner, Invisible Times и др.)
- Вариационные селекторы
- Теговые символы
- Символы двунаправленного переопределения

Полный справочник см. в `ai-chart.txt`.

## CLI — Санитайзер (все 6 языков)

```
partxt <входной_файл> [опции]
```

Опции:
  -o, --output <файл>       Выходной файл (по умолчанию: <входной>.ed.txt)
  -r, --report <файл>       Файл отчёта (по умолчанию: report_<язык>.txt)
  --no-edit                 Не создавать файл .ed.txt
  --no-report               Не создавать файл отчёта
  -w, --no-words            Не включать частотный словарь в отчёт
  --remove-watermark        Удалить AI-водяные знаки (скрытые/невидимые символы)
  -h, --help                Показать справку

### По отдельности

```bash
python3 partxtpy/partxt.py testdata/sample.txt
python3 partxtpy/partxt.py testdata/sample.txt --remove-watermark

cargo run --release --manifest-path partxtrs/Cargo.toml -- testdata/sample.txt
cargo run --release --manifest-path partxtrs/Cargo.toml -- testdata/sample.txt -- --remove-watermark

cd partxtgo && go run . testdata/sample.txt
cd partxtgo && go run . --remove-watermark testdata/sample.txt

cd partxtcpp && make && ./partxt testdata/sample.txt
cd partxtcpp && make && ./partxt testdata/sample.txt --remove-watermark

node partxtnode/partxt.js testdata/sample.txt
node partxtnode/partxt.js testdata/sample.txt --remove-watermark

bun run partxtjs/partxt.js testdata/sample.txt
bun run partxtjs/partxt.js testdata/sample.txt --remove-watermark
```

### Все сразу

```bash
./run_all.sh testdata/sample.txt
```

## CLI — Криминалистическая аналитика AI (только Python)

```bash
python3 parscgptv2.py <текстовый_файл>
```

В корне проекта доступны три варианта аналитических скриптов:

| Скрипт | Описание |
|--------|----------|
| `parscgpt.py` | Начальная версия — базовые эвристические метрики и AI-оценка |
| `parscgptv1.py` | Расширенная — добавлена фильтрация стоп-слов, уровень достоверности, интерпретация, обнаружение подозрительных паттернов |
| `parscgptv2.py` | Полная версия — улучшенная скоринговая модель, чистый вывод, рекомендуется для использования |

### Вычисляемые метрики

| Метрика | Описание |
|---------|----------|
| `lexical_diversity` | Уникальные слова / всего слов (после удаления стоп-слов) |
| `repetition_score` | Доля слов, встречающихся более одного раза |
| `entropy` | Энтропия Шеннона распределения частот слов |
| `burstiness` | Коэффициент вариации длин предложений |
| `pattern_repetition_score` | Доля повторяющихся паттернов длин предложений (S/M/L кодирование) |
| `punctuation_density` | Количество знаков препинания / общее число символов |
| `ai_phrase_hits` | Совпадения с 21 типичной AI-фразой |
| `unicode_symbols` | Количество подозрительных Unicode-символов (тире, кавычки и т.д.) |
| `top_bigrams` | Топ-10 биграмм из отфильтрованного текста |
| `top_trigrams` | Топ-10 триграмм из отфильтрованного текста |

### Оценка вероятности AI

| Условие | Баллы |
|---------|-------|
| Лексическое разнообразие < 0.45 | +20 |
| Энтропия < 5.0 | +20 |
| Взрывообразность < 0.35 | +15 |
| Повторяемость паттернов > 0.35 | +15 |
| Оценка повторяемости > 0.5 | +10 |
| AI-фразы ≥ 3 | +15 |
| Плотность пунктуации > 0.04 | +5 |
| Подозрительные Unicode-символы | +5 |

**Итого** ограничено 100%. Достоверность: низкая (<300 слов), средняя (300–999), высокая (≥1000).

### Вывод включает

- Все сырые метрики с округлёнными значениями
- `estimated_ai_probability` — эвристическая оценка
- `confidence` — на основе длины текста
- `interpretation` — человекочитаемое заключение по каждой метрике
- `overall_profile` — вердикт и положительные сигналы
- `suspicious_patterns` — обнаруженные AI-подобные фразы и триграммы

### Пример вывода

```
=== AI TEXT FORENSIC ANALYSIS ===

word_count: 198
sentence_count: 11
lexical_diversity: 0.832
entropy: 6.655
burstiness: 0.52
estimated_ai_probability: 0%
confidence: low
interpretation:
  lexical_diversity: High lexical diversity → richer and more human-like vocabulary.
  entropy: Moderate entropy.
  burstiness: Moderate burstiness.
overall_profile:
  verdict: Text statistically appears more human-like.
  signals: ['high lexical diversity']

=== END OF REPORT ===
```

## Формат отчёта (санитайзер)

Каждый отчёт содержит:
- Время выполнения
- Режим (замена/удаление + статус удаления водяных знаков)
- Удалённые водяные знаки (с кодами Unicode)
- Заменённые символы (с количеством вхождений)
- Частотный словарь слов (отсортирован по возрастанию)

## Недавние исправления (v0.2.0)

### Улучшения удаления водяных знаков

**Исправлены критические баги в обнаружении AI-водяных знаков во всех 4 реализациях:**

1. **Баг диапазона PUA** — Исправлен диапазон Unicode с `E000-E007F` (573 343 символа) на `E000-E07F` (128 символов)
   - Уменьшен набор символов водяных знаков с 860 305 до 259 символов
   - Исправлено в: Python, Go, Node.js, Rust

2. **Обработка кодовых точек в Node.js** — Заменено `String.fromCharCode()` на `String.fromCodePoint()`
   - Ранее детектировалось 853 ложных водяных знака (ASCII символы)
   - Теперь корректно детектируется 17 водяных знаков

3. **Позиция флагов в Go** — Документировано, что Go требует флаги ДО имени файла
   ```bash
   # Правильное использование для Go:
   cd partxtgo && go run . --remove-watermark input.txt
   ```
