# aiparstxt — Мультиязычный санитайзер текста и ИИ-детектор

Набор утилит командной строки для очистки текстовых файлов путём замены недопустимых символов на '?'. Реализовано на 6 языках для сравнения производительности. Включает удаление ИИ-водяных знаков и **статистический криминалистический анализ** для определения вероятности генерации текста ИИ.

**⚠️ ВАЖНОЕ ОБНОВЛЕНИЕ (август 2026):** После масштабного тестирования с ОПРЕДЕЛЁННО ЧЕЛОВЕЧЕСКИМИ и ОПРЕДЕЛЁННО ИИ образцами, мы создали **honest_ai_detector.py** — единственный детектор с прозрачными ограничениями. См. [Ограничения детекции ИИ](#ограничения-детекции-ии) ниже.

**Доступно на:** [English](README.md) | [Русский](README.RU.md) | [Українська](README.UA.md) | [Português](README.PT.md) | [Français](README.FR.md) | [Deutsch](README.DE.md)


## Возможности

- **Санитайзация текста** — замена недопустимых символов на '?' в 6 языковых реализациях
- **Удаление ИИ-водяных знаков** — удаление невидимых Unicode-символов, вставляемых ИИ-системами
- **Криминалистическая аналитика ИИ** — эвристический статистический анализ для оценки вероятности авторства ИИ
- **Расширенные версии детекции** — улучшенная криминалистическая аналитика доступна для всех 6 языков ⭐
- **Честная детекция ИИ** — прозрачный ИИ-детектор с известными ограничениями ✅

## Допустимые символы

- Цифры: 0-9
- Латинские буквы: A-Z, a-z
- Русские буквы: А-Я, а-я (включая Ё/ё)
- Украинские буквы: ҐґЄєІіЇї
- Знаки препинания и символы: []{}()-=_+!@#$%&*;'/.,<>'"`~:—«»
- Пробельные символы: пробел, табуляция, перевод строки

Все остальные символы заменяются на '?'.

## Удаление ИИ-водяных знаков

Санитайзер поддерживает удаление невидимых символов-водяных знаков, используемых ИИ-системами для маркировки сгенерированного текста:
- Символы нулевой ширины (ZWSP, ZWNJ, ZWJ, ZWNBSP)
- Невидимые символы форматирования (Word Joiner, Invisible Times и др.)
- Вариационные селекторы
- Теговые символы
- Символы двунаправленного переопределения

Полный справочник см. в `ai-chart.txt`.

## CLI — Санитайзер (все 6 языков)

```
partxt <входной_файл> [опции]
```

Опции:
  -o, --output <файл>       Выходной файл (по умолчанию: <входной>.ed.txt)
  -r, --report <файл>       Файл отчёта (по умолчанию: report_<язык>.txt)
  --no-edit                 Не создавать файл .ed.txt
  --no-report               Не создавать файл отчёта
  -w, --no-words            Не включать частотный словарь в отчёт
  --remove-watermark        Удалить ИИ-водяные знаки (скрытые/невидимые символы)
  -h, --help                Показать справку

### По отдельности

```bash
# Стандартные версии
python3 partxtpy/partxt.py testdata/sample.txt
python3 partxtpy/partxt.py testdata/sample.txt --remove-watermark

# Расширенные версии с ИИ-аналитикой ⭐
python3 partxtpy/partxt-ext.py testdata/sample.txt
python3 partxtpy/partxt-ext.py testdata/sample.txt --remove-watermark

cargo run --release --manifest-path partxtrs/Cargo.toml -- testdata/sample.txt
cargo run --release --manifest-path partxtrs/Cargo.toml --bin partxt-ext -- testdata/sample.txt --remove-watermark

cd partxtgo && go run . testdata/sample.txt
cd partxtgo && go run main-ext.go testdata/sample.txt --remove-watermark

cd partxtcpp && make && ./partxt testdata/sample.txt
cd partxtcpp && make && ./partxt-ext testdata/sample.txt --remove-watermark

node partxtnode/partxt.js testdata/sample.txt
node partxtnode/partxt-ext.js testdata/sample.txt --remove-watermark

bun run partxtjs/partxt.js testdata/sample.txt
bun run partxtjs/partxt-ext.js testdata/sample.txt --remove-watermark
```

```bash

./run_all_extended.sh testdata/sample.txt
```

## CLI — Криминалистическая аналитика ИИ

### ✅ ЧЕСТНЫЙ детектор ИИ (РЕКОМЕНДУЕТСЯ)

```bash
python3 honest_ai_detector.py <текстовый_файл>
```

**Единственный детектор с прозрачными ограничениями:**

✅ **Правильно детектирует человеческие тексты** (5% для реальной статьи 2014 года)  
✅ **Честно признаёт ограничения** (10% + предупреждения для ИИ-текста)  
✅ **Не даёт ложных гарантий** (явно предупреждает о ложно-отрицательных результатах)

**Принципы:**
- Лучше НЕ детектировать ИИ, чем ложно обвинить человека
- Проверяет ТОЛЬКО технически обнаружимые признаки
- Честно заявляет о своих ограничениях

**Методология:**
- ✅ Проверяет водяные знаки ИИ (zero-width characters)
- ✅ Проверяет аномалии форматирования
- ❌ НЕ использует лексические маркеры (ложно-положительные на профессиональный стиль)
- ❌ НЕ использует статистику (вариативная)
- ❌ НЕ использует стилеметрию (ненадёжная)

**Что МОЖЕТ детектировать:**
- Низкокачественный ИИ (с водяными знаками, аномалиями форматирования)
- Человеческие тексты с высокой точностью

**Что НЕ МОЖЕТ детектировать:**
- Высококачественный ИИ (без технических признаков)
- Техническая документация (может быть ложно-отрицательной)
- ИИ-тексты, отредактированные человеком

## Ограничения детекции ИИ ⚠️

### Реальность

✅ **ЧЕСТНЫЙ детектор** — единственный правильный подход к детекции ИИ

❌ **Все остальные детекторы** — дают ложные гарантии и не работают правильно

### Почему детекторы НЕ РАБОТАЮТ для ИИ-текстов

1. **README-файлы — особый случай**
   - Техническая документация структурирована по определению
   - Использует формальный стиль
   - Имеет стандартные фразы ("установка", "использование", "примеры")
   - Отсутствует личный опыт

2. **ИИ-генерация стала слишком качественной**
   - Современные ИИ пишут естественно
   - Не используют zero-width watermarks
   - Не делают ошибок форматирования
   - Имитируют человеческий стиль

3. **Отсутствуют надёжные технические признаки**
   - Водяные знаки: не используются в качественном ИИ
   - Аномалии форматирования: отсутствуют в качественном ИИ
   - Статистические признаки: слишком вариативны

### Что действительно работает

**Для человеческих текстов:**
```bash
python3 honest_ai_detector.py human_text.txt
```
**Ожидаемый результат:** 5% + "НЕ НАЙДЕНО ПРИЗНАКОВ ИИ" ✅

**Для ИИ-текстов (если есть технические признаки):**
```bash
python3 honest_ai_detector.py ai_text.txt
```
**Ожидаемый результат:** Высокая вероятность + найденные признаки ✅

**Для качественного ИИ (README, техдоки):**
```bash
python3 honest_ai_detector.py readme.md
```
**Ожидаемый результат:** 10-35% + ЧЕСТНЫЕ предупреждения ⚠️

## Стандартные метрики (расширенные версии)

⚠️ **ПРИМЕЧАНИЕ:** Эти метрики предоставлены для функций анализа текста, но их надёжность для детекции ИИ ограничена.

| Метрика | Описание | Значение для детекции ИИ |
|--------|-------------|---------------------|
| `lexical_diversity` | Уникальные слова / всего слов (после удаления стоп-слов) | ИИ имеет меньшее разнообразие |
| `repetition_score` | Доля слов, встречающихся более одного раза | ИИ повторяет чаще |
| `entropy` | Энтропия Шеннона распределения частот слов | ИИ имеет ненормально равномерное распределение |
| `burstiness` | Коэффициент вариации длин предложений | ИИ имеет чрезмерно однородную структуру предложений |
| `pattern_repetition` | Доля повторяющихся паттернов длин предложений | ИИ использует шаблонные паттерны |
| `punctuation_density` | Количество знаков препинания / общее число символов | ИИ может переиспользовать пунктуацию |
| `ai_phrase_hits` | Совпадения с типичными ИИ-фразами (70+) | Прямой признак ИИ |
| `unicode_symbols` | Количество подозрительных Unicode-символов | Технические маркеры ИИ |
| `avg_word_length` | Средняя длина слов | ИИ использует более простой словарный запас |
| `word_length_variance` | Вариация длин слов | ИИ-тексты более однородные |
| `confidence` | На основе количества слов (LOW <300, MEDIUM 300-999, HIGH ≥1000) | Индикатор надёжности |

## Формат отчёта (санитайзер)

Каждый отчёт включает:
- Время выполнения
- Режим (замена/удаление + статус удаления водяных знаков)
- Удалённые водяные знаки (с Unicode code points)
- Заменённые символы (с количеством)
- Частотный словарь (по возрастанию)

**Расширенные версии** дополнительно включают:
- Секцию метрик ИИ-криминалистики
- Оценку вероятности ИИ с уровнем достоверности
- Анализ сигналов с визуальными индикаторами
- Специфическую интерпретацию по метрикам
